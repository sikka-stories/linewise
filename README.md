# Linewise

A maths notebook that checks your working, with lessons, a calculator and graphs.

**Open it:** the address GitHub Pages gives this repository (Settings, Pages).

These are the built website files only.

## Turning on the AI
The AI features use your own free Google Gemini key:
1. Open https://aistudio.google.com/apikey and sign in with a Google account.
2. Click **Create API key** (let it make a project if it asks) and copy the key.
3. In Linewise, open **Settings**, paste the key into **Your AI key**, and press **check and save**.

The key stays on your device and is only ever sent to Google.

See privacy.html and terms.html.
